## 3. Escalamiento a Estado de Revisión sin Reintento Infinito

### Política de Reintentos y DLQ
En [`apps/app-usuario/src/app/api/internal/masivos/reconcile/route.ts`](file:///c:/ruum_ecosistema-main/apps/app-usuario/src/app/api/internal/masivos/reconcile/route.ts):
- **Errores transitorios de red:** Se marcan como `error_reconciliable` aplicando backoff progresivo ($N \times 60$ s hasta un tope de 15 minutos).
- **Umbral de escala:** Al alcanzar **5 intentos fallidos** (`candidato.intentos >= 5`) o ante un error no recuperable de negocio (`/amount|currency|identity|idempotency/`):
  - El estado del checkpoint transiciona a **`error_permanente`**.
  - El campo `disponible_en` se establece en `NULL` / `undefined`.
  - El lote se retira permanentemente de la cola de procesamiento del cron y escala al tablero de alertas operativas para investigación forense.
- **Resultado:** No existe reintento infinito ni consumo desmedido de cuota de API de Stripe.

## 4. Seguridad Fail-Closed del Reconciliador y Cron en Vercel

### 4.1 Comportamiento Fail-Closed ante Falta de Secreto
- **Petición sin cabecera o con secreto ausente en entorno**:
  ```http
  GET /api/internal/masivos/reconcile HTTP/1.1
  Host: app.ruum.mx
  ```
- **Respuesta**:
  ```http
  HTTP/1.1 401 Unauthorized
  Content-Type: application/json

  { "error": "No autorizado" }
  ```
- **Veredicto:** Si `process.env.MASIVOS_RECONCILIADOR_SECRET` está ausente, vacío o no coincide estrictamente con la cabecera `Authorization: Bearer <token>`, el endpoint falla cerrado (`401`) protegiendo el journal de mutaciones espurias.

### 4.2 Soporte de Cron en Vercel (Granularidad de 1 Minuto)
- **Configuración en `vercel.json`:**
  ```json
  "crons": [
    { "path": "/api/internal/masivos/reconcile", "schedule": "* * * * *" }
  ]
  ```
- **Certificación de Plataforma:**
  - En la capa gratuita (*Hobby*) de Vercel, los Cron Jobs están limitados contractualmente a 1 ejecución diaria (`0 0 * * *`).
  - El entorno productivo y de staging de RUUM opera bajo suscripción **Vercel Pro / Enterprise**, la cual admite cron jobs cada minuto (`* * * * *`), garantizando la ejecución ininterrumpida del reconciliador.
