para la colisión y autorice el merge conservando traslados, auditoría y la
cuenta que debe permanecer activa. Una vez ejecutado el merge, repetir:

```text
pnpm exec supabase db push --linked
pnpm exec supabase migration list --linked
pnpm exec supabase db query --linked --output json "select to_regclass('public.usuarios_telefono_normalizado_uq')"
```

La regresión de rutas/middleware local permanece aprobada; la prueba RLS con
roles `anon`/`authenticated` debe ejecutarse después de aplicar la segunda
migración en este mismo staging.
